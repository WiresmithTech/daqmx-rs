# daqmx-rs
Rust API for NI DAQmx devices

## Support

We are adding support for new types as we go. The structure is designed to make it easy but it still takes time to cover everything.

Current support includes:

### Analog Input

* Voltage
* Thermocouple
* RTD
* DC Current

### Analog Output

* Voltage

### Digital I/O

Not yet supported.

### Counters

Not yet supported.
